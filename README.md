# coolpc-crawler

每日抓取原價屋網路部的組裝相簿項目數，寫入 Google 試算表。

## 日期尚未上架與讀取失敗

- 年份目錄已載入，但沒有指定日期資料夾：記錄為 `PENDING`，保留試算表原值，本次執行正常結束。
- 瀏覽器、年份目錄、已存在的日期相簿或組裝數讀取失敗：記錄出錯階段及例外類型，最多再試三次；仍失敗就讓執行回報失敗。
- 成功取得的數值（包括 0）才寫入試算表，成功項目不受其他日期的失敗影響。

每次處理近五天與先前尚未完成的日期。`pending_dates.json` 僅包含待補抓日期，不含憑證；GitHub Actions 透過快取在執行之間保存它，失敗時也會保存。只有試算表寫入成功才移除該日期，超過五天仍可補抓。若快取被清除，會從近五天重新建立清單；需要補更早日期時，可在本機清單加入七碼民國日期。

補抓會搜尋整張試算表，同日期覆蓋原列，避免舊日期新增重複資料。工作流程限制同時只執行一次。

## 本機執行

安裝 `selenium webdriver-manager gspread oauth2client`，在工作目錄放置 `service_account.json` 後執行 `python main.py`。憑證與待補抓清單均不提交到 Git。

執行不連線、不使用憑證的回歸測試：

```sh
python -m unittest discover -s tests -v
```
